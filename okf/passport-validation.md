# Passport photo validation

ShareCapsule provides country-specific passport photo validation routes.

## Routes

- Supported tools: https://sharecapsule.app/passport-validation/
- India: https://sharecapsule.app/passport-validation/in/
- United States: https://sharecapsule.app/passport-validation/us/

## Intended workflow

1. Select the relevant country.
2. Upload a photograph.
3. Review dimension, composition, background, and file-related checks supported by the page.
4. Correct or export the image when that capability is available.

## Important limitation

The tool provides technical guidance and automated checks. It does not guarantee acceptance by a passport authority. Users should compare the result with the latest official government photo requirements before submission.

## Privacy

Processing may occur in the browser or through a configured service depending on the route. Users should avoid uploading unrelated sensitive documents.
