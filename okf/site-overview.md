# ShareCapsule

ShareCapsule is a public web platform for sharing useful audio, video, ideas, event information, cards, and practical tools.

## Primary goals

- Make useful content easy to open and share.
- Provide focused utilities without requiring an account where possible.
- Support mobile-first access and WhatsApp-friendly sharing.
- Help users investigate questionable news before forwarding it.

## Major public routes

- Home: https://sharecapsule.app/
- News investigation: https://sharecapsule.app/factcheck/
- Passport photo tools: https://sharecapsule.app/passport-validation/
- India passport photo validation: https://sharecapsule.app/passport-validation/in/
- United States passport photo validation: https://sharecapsule.app/passport-validation/us/
- Public events in Tamil Nadu: https://sharecapsule.app/events/public/in/tn
- Open Knowledge bundle: https://sharecapsule.app/okf/

## Content model

The home experience presents releases or tools as shareable cards. Individual features may use browser-local processing, static content, or Cloudflare-backed APIs depending on the task.
