# Public events discovery

The public events feature surfaces events that members of the public can attend or apply to attend.

## Current regional route

- Tamil Nadu, India: https://sharecapsule.app/events/public/in/tn

## Source expectations

Event entries should use authenticated or official sources where available and include references users can open independently.

## Limitations

Schedules, eligibility, venue access, application windows, and cancellations can change. Users should verify the latest details with the event organizer or official source before travel or payment.
