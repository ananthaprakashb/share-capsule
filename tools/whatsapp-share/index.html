SHARECAPSULE TOOL

YouTube → WhatsApp Status

Split a video you own into short WhatsApp-friendly clips. Processing stays on your device. Each result card links back to the original YouTube video.

1. Add the YouTube source

This link is preserved as the source and opens when a result preview is tapped.

2. Choose your video

Use an MP4, MOV or WebM file you own or have permission to reuse. ShareCapsule does not download YouTube videos.

3. Create Status clips

The tool tries the fast FFmpeg engine first. If that runtime is blocked, compatible browsers automatically fall back to local real-time recording.

4. Share

Tap a preview to open YouTube. Share the clip through the device share sheet or download it.

Resilient processing: blocked CDN assets no longer stop the workflow when your browser supports native media recording. Native fallback runs locally and may take approximately the length of the source video.
WhatsApp limitation: an MP4 itself cannot contain a clickable external hyperlink in Status. Add the YouTube URL separately in WhatsApp; on ShareCapsule, each clip preview opens the source video.
